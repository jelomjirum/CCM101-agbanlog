
# Amazon Web Services (AWS) Research

## 1. Brief Overview

Amazon Web Services (AWS) is a public cloud platform provided by Amazon. It offers computing, storage, networking, databases, security, analytics, and other services that organizations can use to build and operate applications.

## 2. Global Infrastructure

AWS operates cloud infrastructure across multiple geographic Regions and Availability Zones. These locations help customers deploy workloads in suitable geographic areas and design applications for availability and resilience.

Official reference: https://aws.amazon.com/about-aws/global-infrastructure/

## 3. Cloud Management Console

The AWS Management Console is a web-based interface for accessing and managing AWS services. Users can configure resources, monitor workloads, and manage access according to their permissions.

Official reference: https://console.aws.amazon.com/

## 4. Four Core Services

1. **Amazon EC2:** Provides virtual servers for running applications.
2. **Amazon S3:** Provides object storage for files and data.
3. **Amazon VPC:** Provides logically isolated networking resources.
4. **AWS IAM:** Manages identities, roles, and permissions.

## 5. Three Advantages

1. Broad selection of cloud services for different workloads.
2. Flexible infrastructure that can scale according to demand.
3. Global infrastructure that supports deployments in multiple geographic locations.

## 6. Typical Enterprise Use Cases

Enterprises use AWS for website hosting, application development, data storage, backup, analytics, disaster recovery, and machine learning workloads.
