# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud is a public cloud platform that provides computing, storage, networking, databases, analytics, AI, and machine learning services. It helps organizations build, deploy, and manage applications and data workloads.

## 2. Global Infrastructure

Google Cloud operates infrastructure across multiple geographic regions and zones. Customers can select deployment locations and design resilient applications based on their availability and performance requirements.

Official reference: https://cloud.google.com/about/locations

## 3. Cloud Management Console

The Google Cloud console is a web-based interface for managing projects, cloud resources, services, permissions, and monitoring. It provides access to tools for configuring and operating Google Cloud workloads.

Official reference: https://console.cloud.google.com/

## 4. Four Core Services

1. **Compute Engine:** Provides virtual machines.
2. **Cloud Storage:** Provides object storage.
3. **Virtual Private Cloud (VPC):** Provides networking for cloud resources.
4. **Cloud IAM:** Controls access to Google Cloud resources.

## 5. Three Advantages

1. Strong AI, machine learning, and data analytics capabilities.
2. Google Kubernetes Engine (GKE) provides managed Kubernetes.
3. Networking and infrastructure options support globally distributed applications.

## 6. Typical Enterprise Use Cases

Organizations use Google Cloud for AI development, machine learning, data analytics, containerized applications, website hosting, and large-scale data processing.
