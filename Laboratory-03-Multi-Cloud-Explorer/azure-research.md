# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a public cloud platform that provides computing, storage, networking, databases, identity, analytics, and AI services. It supports organizations building new applications and migrating existing systems to the cloud.

## 2. Global Infrastructure

Azure provides cloud infrastructure across geographic regions and availability options. Organizations can choose suitable locations and architectures based on performance, availability, compliance, and business requirements.

Official reference: https://azure.microsoft.com/en-us/explore/global-infrastructure/

## 3. Cloud Management Console

The Azure portal is a web-based interface for creating, configuring, monitoring, and managing Azure resources. It also supports resource organization, access management, and operational monitoring.

Official reference: https://portal.azure.com/

## 4. Four Core Services

1. **Azure Virtual Machines:** Provides virtualized computing resources.
2. **Azure Blob Storage:** Stores unstructured data as objects.
3. **Azure Virtual Network:** Provides private networking for Azure resources.
4. **Microsoft Entra ID and Azure RBAC:** Support identity management and access control.

## 5. Three Advantages

1. Strong integration with Microsoft technologies.
2. Supports hybrid cloud environments and existing enterprise systems.
3. Offers a broad selection of computing, data, security, and AI services.

## 6. Typical Enterprise Use Cases

Organizations use Azure for Windows Server workloads, enterprise applications, Microsoft ecosystem integration, application hosting, data management, and hybrid cloud solutions.
