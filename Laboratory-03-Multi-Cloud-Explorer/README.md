# Laboratory Activity 3: Multi-Cloud Explorer

## 1. Mission Overview

This mission explores Amazon Web Services, Microsoft Azure, and Google Cloud Platform. It compares their core services and evaluates which platform may be appropriate for different business requirements.

## 2. Objectives

- Research the three major public cloud providers.
- Compare equivalent cloud infrastructure services.
- Recommend platforms for different client scenarios.
- Investigate a Linux environment using KillerCoda.
- Maintain a structured GitHub Cloud Computing Portfolio.

## 3. Tools Used

- GitHub
- KillerCoda Playground
- Linux terminal
- Official AWS, Azure, and Google Cloud documentation
- Markdown
- Web browser

## 5. Possible Cloud Hosting Services

If this Linux server were migrated to a public cloud, equivalent virtual machine services could host a compatible Linux operating system.

- **AWS:** Amazon EC2
- **Microsoft Azure:** Azure Virtual Machines
- **Google Cloud:** Compute Engine

The final virtual machine size and configuration should be selected based on the actual CPU, memory, disk, networking, and application requirements. These services can host Linux workloads, but a migration would require additional planning and testing.

## 7. Skills Learned

This activity develops cloud research, service comparison, business analysis, Linux investigation, technical writing, and GitHub organization skills.

## 8. Conclusion

The mission demonstrates that AWS, Azure, and Google Cloud provide comparable core infrastructure capabilities while offering different strengths. Selecting a cloud provider requires matching technical capabilities to the organization's business needs, budget, and operational requirements.
