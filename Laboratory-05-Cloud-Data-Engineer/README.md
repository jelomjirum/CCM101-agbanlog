# Laboratory Activity 5: The Cloud Data Engineer

## 1. Mission Overview

This laboratory activity focuses on cloud storage and the deployment of MinIO using Docker. MinIO is an S3-compatible object storage server that allows users to store and manage files such as images, videos, and backups.

In this activity, I will learn how to deploy MinIO, access its web console, create a storage bucket named `client-photos`, and upload a sample file.

## 2. Objectives

- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy a MinIO server using Docker.
- Access the MinIO Web Console through port 9001.
- Create a bucket named `client-photos`.
- Upload a sample image or text file.
- Document the deployment process using Markdown.
- Organize laboratory files in my GitHub portfolio.

## 3. Tools Used

- **KillerCoda:** Provides the Linux playground environment.
- **Docker:** Runs the MinIO server as a container.
- **MinIO:** Provides S3-compatible object storage.
- **GitHub:** Stores laboratory documentation and screenshots.
- **Web Browser:** Accesses the MinIO Web Console.

## 4. Skills Learned

- Understanding different types of cloud storage.
- Running Docker commands in a Linux terminal.
- Using environment variables to configure a container.
- Mapping container ports to access a web service.
- Creating storage buckets and uploading objects.
- Documenting technical procedures using Markdown.
- Organizing a cloud computing portfolio on GitHub.
