# Laboratory Activity 5: The Cloud Data Engineer

## Mission Overview
This mission focuses on cloud storage and deploying an S3-compatible object storage server using MinIO and Docker. The goal is to create a bucket named `client-photos` and upload a sample file through the MinIO Web Console.

## Objectives
- Differentiate Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console through port 9001.
- Create the `client-photos` bucket and upload a sample object.
- Document the deployment process using Markdown.

## Tools Used
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web browser

## Skills Learned
- Comparing cloud storage types.
- Running a containerized storage server.
- Using Docker environment variables and port mapping.
- Creating buckets and uploading objects.
- Documenting cloud operations in Markdown.

## Evidence
Screenshots of the actual deployment and bucket upload will be saved in the `screenshots` folder.

## Conclusion
This activity demonstrates how Docker and MinIO can be used to practice object storage operations in a cloud-like environment.
