
# Laboratory 09 - Cloud Automation Engineer Reflection

## Mission Reflection

During Laboratory 09, I learned how automation can make cloud server management easier and more organized. Managing a large number of servers manually requires a lot of time and effort, especially when performing the same tasks repeatedly. Through automation, system administrators can complete routine operations more quickly while reducing mistakes caused by manual work.

One important thing I realized is that automation should always be used carefully. Although scripts can save time, they can also create problems if the commands are incorrect. For example, a script containing an accidental delete command could remove valuable information from hundreds or even thousands of servers. Because of this, I learned that testing scripts in a safe environment and checking their contents before execution are necessary steps.

I also discovered the difference between Bash scripting and Docker Compose. In Laboratory 06, we used a YAML file to configure and deploy multiple Docker containers. In this laboratory, Bash was used to execute Linux commands and create an automated backup process. Docker Compose focuses on managing containerized applications, while Bash scripting helps automate different system operations.

Reflecting on Laboratories 01 to 09, I can say that my knowledge of cloud computing has expanded. Before completing these activities, I had limited experience with cloud technologies. As the laboratories continued, I became more familiar with Linux commands, Docker containers, database services, server monitoring, firewall configuration, and automated tasks.

The role I found most interesting was Cloud Automation Engineer because I enjoyed learning how a few lines of code could perform useful operations without repeating commands manually. Creating a backup script helped me appreciate the value of scripting in real-world server administration.

Overall, Laboratory 09 strengthened my technical knowledge and taught me that successful cloud management requires efficiency, accuracy, and proper planning.
