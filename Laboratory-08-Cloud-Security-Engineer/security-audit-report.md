
# Cloud Security Assessment Report

## Mission 8: The Cloud Security Engineer

### 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege is a security practice that limits the access rights of users, programs, and services based on their responsibilities. In a cloud environment, this principle helps prevent unnecessary access to sensitive information and important system settings. By providing only the required permissions, administrators can minimize security threats and reduce the damage caused by compromised accounts.

### 2. Attack Surface

The attack surface represents the different areas of a computer system that may be vulnerable to cyberattacks. For virtual machines, these areas can include active network connections, accessible ports, installed applications, and background services. Reducing the number of unnecessary services and closing unused ports can improve the overall protection of the server.

### 3. Default Deny Policy

A Default Deny Policy is a firewall security approach that automatically rejects incoming connections unless they are specifically permitted. This method provides stronger protection because only authorized network traffic can reach the server. Instead of identifying and blocking every possible threat individually, the system prevents unknown connections from entering in the first place.
This security assessment highlights the importance of controlling access, minimizing vulnerabilities, and properly configuring firewall protection in a cloud environment. Applying the Principle of Least Privilege, reducing the attack surface, and implementing a Default Deny Policy can help strengthen server security. Regular monitoring and maintenance are also necessary to maintain a safer and more reliable cloud infrastructure.
