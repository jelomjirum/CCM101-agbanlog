# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

In my opinion, compute resources are one of the most important components of cloud infrastructure because they run applications, process instructions, and perform tasks. Without sufficient computing resources, applications may become slow or fail to handle user requests. However, compute resources must work together with storage and networking to provide a complete cloud service.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for servers and applications. It includes command-line tools that allow administrators to inspect system resources, manage files, configure networking, and troubleshoot problems. Learning Linux commands helped me understand how engineers investigate and manage server environments.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important before deploying infrastructure because it records system requirements, available resources, configurations, and design decisions. It helps engineers plan deployments, communicate with their teams, and identify possible limitations before problems occur. Clear documentation also makes troubleshooting and future maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

During this laboratory activity, I learned how to use Linux commands to inspect operating system information, CPU resources, memory, disk usage, mounted file systems, hostname, and IP addresses. I also learned about the compute, storage, networking, and identity management services offered by AWS, Microsoft Azure, and Google Cloud. Creating a cloud infrastructure diagram and organizing Markdown files helped improve my technical documentation skills.

Overall, this mission improved my understanding of cloud infrastructure planning and Linux server investigation.
