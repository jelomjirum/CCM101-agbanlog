# Mission 1 Reflection

In this laboratory activity, I learned how to access a Linux environment using KillerCoda and execute basic Linux commands. I practiced checking my username, working directory, hostname, operating system, CPU, memory, and disk space.

I also learned how to create directories and Markdown files to organize my work. Creating a GitHub repository helped me understand how to maintain a portfolio for my cloud computing activities.

This activity improved my familiarity with the Linux terminal and technical documentation. I learned that accurate information and organized files are important when working with cloud systems.
