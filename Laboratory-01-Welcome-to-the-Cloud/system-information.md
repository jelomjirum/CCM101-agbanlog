# System Information

## Linux Distribution
To be filled in using the output of `cat /etc/os-release`.

## Kernel Version
To be filled in using the output of `uname -r`.

## CPU Information
To be filled in using the output of `lscpu`.

## Total Memory
To be filled in using the output of `free -h`.

## Available Disk Space
To be filled in using the output of `df -h`.
