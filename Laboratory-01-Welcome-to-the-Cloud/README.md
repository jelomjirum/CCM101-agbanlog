# Laboratory Activity 1
## Mission 1: Welcome to the Cloud

## Mission Overview
This mission introduces the Linux environment, basic system information, file management, and GitHub portfolio documentation.

## Objectives
- Access a Linux environment using KillerCoda.
- Identify basic system information.
- Create and organize directories and files.
- Document activities using Markdown.
- Build a GitHub Cloud Computing Portfolio.

## Activities Performed
- Created a Linux user.
- Checked the username, working directory, and hostname.
- Collected Linux, kernel, CPU, memory, and disk information.
- Created a workspace and Markdown file.
- Created a GitHub repository.

## Linux Commands Used
- `whoami`
- `pwd`
- `hostname`
- `cat /etc/os-release`
- `uname -r`
- `lscpu`
- `free -h`
- `df -h`
- `mkdir`
- `find`
- `cat`

## Skills Learned
I practiced using Linux commands, organizing files, collecting system information, and documenting technical work using Markdown and GitHub.
