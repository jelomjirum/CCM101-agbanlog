# Laboratory Reflection – Cloud Operations Engineer

## 1. Why is it important to establish a system resource baseline?

A system resource baseline helps an engineer understand the normal memory, disk, and CPU conditions of an environment. By checking these resources before deploying applications, an engineer can identify possible limitations and compare resource usage later.

## 2. How does the `docker logs` command help in troubleshooting?

The `docker logs` command displays messages generated by a container. These messages can show incoming requests, errors, and other application events. Engineers can use the logs to investigate problems and understand how an application behaves.

## 3. What is the difference between logs and metrics?

Logs contain records of events that happen inside an application or container. Metrics are numerical measurements such as CPU usage, memory consumption, and request counts. Logs help explain events, while metrics help measure performance and resource usage.

## 4. How can monitoring tools such as Prometheus and Grafana help cloud engineers?

Prometheus collects and stores numerical metrics from monitored systems and applications. Grafana presents metrics through dashboards and visualizations. These tools help engineers monitor performance, recognize unusual patterns, and investigate potential issues.

## 5. What Linux troubleshooting skills did you practice?

I practiced checking memory with `free -h`, checking disk space with `df -h /`, inspecting running processes with `top`, and reviewing container activity through Docker commands. These skills are useful when checking the health of a Linux environment.
