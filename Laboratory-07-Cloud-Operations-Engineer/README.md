# Laboratory Activity 7 – Cloud Operations Engineer

## Mission Overview

This laboratory activity focuses on basic cloud operations, system resource monitoring, container management, and troubleshooting.

## Objectives

- Monitor system memory and disk usage.
- Deploy and manage an Nginx Docker container.
- Generate HTTP requests and observe server responses.
- Inspect container logs to identify errors.
- Monitor container CPU and memory usage.

## Tools Used

- KillerCoda Linux Terminal
- Docker
- Nginx
- Linux monitoring commands
- curl

## Activities Completed

1. Checked system memory using `free -h`.
2. Checked disk usage using `df -h /`.
3. Inspected running processes using `top`.
4. Deployed an Nginx container using Docker.
5. Tested HTTP responses using `curl`.
6. Reviewed container logs using `docker logs`.
7. Monitored container resources using `docker stats`.
